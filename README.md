# T&T Store

Website nước hoa mini, dựng riêng từ giao diện Kinguyenperfume.

- Mở `dist/index.html` qua static server để xem.
- Triển khai Netlify: Publish directory `dist`, không cần lệnh build.
- Dán URL Apps Script vào biến `URLscript` trong `dist/app.js` để nhận đơn. Hiện URL để trống theo yêu cầu.
- Giá, tên và dung tích lấy từ tên 14 file ảnh người dùng cung cấp. Không áp dụng giảm giá combo chưa được cung cấp; mua 2 chai tính gấp đôi giá 1 chai. Phí ship kế thừa: 1 chai 22.000đ, 2 chai miễn ship.
