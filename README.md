# T&T Store

Website nước hoa mini, dựng riêng từ giao diện Kinguyenperfume.

- Mở `dist/index.html` qua static server để xem.
- Triển khai Netlify: Publish directory `dist`, không cần lệnh build.
- Dán URL Apps Script vào biến `URLscript` trong `dist/app.js` để nhận đơn. Giữ URL Web App đang được cấu hình.
- Danh mục gồm 4 mẫu từ bộ ảnh mới: Chance Eau Fraîche EDT 7.5ml, Chance Eau Tendre EDT 7.5ml, Miss Dior Blooming Bouquet 5ml và Chance EDP vàng 7.5ml. Đồng giá 239.000đ/lọ; 1 lọ + 21.000đ ship = 260.000đ; 2 lọ 478.000đ, miễn phí ship.
